# 密码算法实现与测试

## 实现范围

第二阶段提供 `lab.crypto` 公共接口，使用一次性字节串计算。

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `sha256(data)` | `bytes` 消息 | 32 字节摘要 |
| `hmac_sha256(key, data)` | `bytes` 密钥和消息 | 32 字节认证标签 |
| `verify_hmac_sha256(key, data, tag)` | `bytes` 密钥、消息及完整标签 | 验证结果 `bool` |

接口要求调用者显式编码文本。参数类型不符合要求时抛出 `TypeError`。标签长度不等于 32 字节时返回 `False`。等长标签逐字节累积异或差异后判定结果。

算法模块使用 Python 的整数、移位、位运算和字节处理完成计算。HMAC 调用项目自行实现的 SHA-256。测试中的 `hashlib` 和 `hmac` 用于独立对照。

## SHA-256

实现对原始消息追加 `0x80`，再补零，使长度达到模 64 余 56 字节，最后追加原始位长度的 8 字节大端表示。按 64 字节分组，将 16 个输入字扩展为 64 个字，执行 64 轮压缩并累加到摘要状态。整数加法和循环右移使用掩码保持 32 位语义。最终以大端方式输出 8 个状态字。

算法规范参考 FIPS 180-4，标准消息及摘要参考 RFC 6234 第 8.5 节中的 SHA-256 测试数据。[FIPS 180-4](https://csrc.nist.gov/pubs/fips/180-4/upd1/final)、[RFC 6234](https://www.rfc-editor.org/rfc/rfc6234.txt)

## HMAC-SHA-256

密钥超过 64 字节时先计算 SHA-256，将所得密钥补零至 64 字节。分别与 `0x36` 和 `0x5c` 异或形成内外层填充，按以下公式生成认证标签。[RFC 2104 第 2 节](https://www.rfc-editor.org/rfc/rfc2104#section-2)

```text
inner = SHA256((padded_key XOR ipad) || data)
tag   = SHA256((padded_key XOR opad) || inner)
```

## 测试依据与主要用例

测试使用标准库 `unittest` 运行，固定向量的预期结果直接保存在测试代码中，独立对照的预期结果由 Python 标准库生成。随机测试使用固定种子，便于复现。

| 类别 | 主要用例 | 预期结果 | 本次实际结果 |
| --- | --- | --- | --- |
| SHA-256 固定向量 | 空消息、`abc`、56 字节标准消息、一百万个 `a` | 与固定摘要逐字节一致 | 全部通过 |
| SHA-256 填充与分组边界 | 0、1、54、55、56、57、63、64、65、119、120、127、128、129、255、256 字节 | 与 `hashlib.sha256` 一致 | 全部通过 |
| SHA-256 二进制与文本 | 全部 256 种字节值、零与高位字节、UTF-8 中文及 emoji | 与独立实现一致 | 全部通过 |
| SHA-256 随机与状态 | 40 组固定种子输入、交错重复调用 | 与独立实现一致，调用之间状态独立 | 全部通过 |
| HMAC 固定向量 | RFC 4231 用例 1–4、6–7 | 完整标签与公开结果一致，验证成功 | 全部通过 |
| HMAC 截断向量 | RFC 4231 用例 5 | 前 16 字节与公开结果一致，验证接口拒绝截断标签 | 通过 |
| HMAC 密钥与消息边界 | 8 种密钥长度与 10 种消息长度组合，含空密钥、空消息和 64/65 字节密钥 | 80 组结果与标准库一致 | 全部通过 |
| HMAC 随机输入 | 30 组固定种子的密钥和消息 | 与 `hmac` 一致 | 全部通过 |
| HMAC 错误输入 | 错误密钥、正文变化、标签每个位置单比特翻转、错误标签长度 | 验证返回 `False` | 全部通过 |
| 消息编码与认证 | 对 `Message.to_bytes()` 认证，修改会话、通信方向、序号或正文 | 原消息成功，修改后的消息失败 | 全部通过 |
| 接口类型 | 字符串、`None`、整数、`bytearray`、`memoryview` | 抛出 `TypeError` | 全部通过 |

HMAC 固定向量来自 RFC 4231 第 4 节。用例 5 提供 128 位截断结果，测试只将计算结果的前 16 字节与该结果对照。实验接口统一生成和验证完整的 256 位标签。[RFC 4231](https://www.rfc-editor.org/rfc/rfc4231#section-4)
